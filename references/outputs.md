# 产出物模板（outputs.md）

四层产出：单次（察觉报告）/ 周期（周报月报）/ 长期（认知画像）/ 对外（脱敏素材）。

## 一、单次：察觉报告 + 动作卡

### 察觉报告模板（对话内输出，默认不落盘）

```
【事件】一句话还原发生了什么（客观事实）
【情绪】具体情绪 + 身体反应（如果有）
【三层拆解】
· 心理层：你的 XX 偏差/回路在起作用——证据：你说过……
· 社经层：但这里有 XX 结构——机制是……
· 历史层：放在长尺度看，你在 XX 阶段——典型剧本是……
【一句真话】你可能不想听，但……
【纠正动作】明天只做这一件：……
```

### 动作卡（可口头给，也可入卡）

- 动作必须**可验证**（能判断做没做），不写"调整心态"这类不可验证词。
- 每次只给 1 个。

## 二、周期：察觉周报 / 月报

> 用户要求"周报/月报/复盘"时，先读画像数据（`assets/portrait-wall.html` 的 DATA 或对话内累积记录），聚类后输出。

### 周报结构

1. **本周概况**：察觉次数、连续天数、新增卡数
2. **高频触发点**：哪些事件类型反复出现（如"客户改需求""深夜刷手机"）
3. **重复归因偏差**：同一类归因错误出现几次（如"总把结构问题算到自己头上"）
4. **能量泄漏点**：哪些场景持续消耗（焦虑/失眠/拖延对应的事件）
5. **一句趋势真话**：本周最该改的一个模式
6. **下周一个动作**

### 月报结构（周报 + 增量）

1. 月度画像变化（六维进度对比月初/月末）
2. 模式库 Top3（本月最顽固的三个模式）
3. 改善证据（哪些动作确实落地了、结果如何）
4. 下月主题（聚焦一个维度）

## 三、长期：认知画像 / 年度对比

- 画像数据按 `portrait.md` 规则维护在展示页 DATA 中。
- 年度对比：年初 vs 年末的六维分布、模式库变化、徽章解锁情况，输出"年度察觉报告"。

## 四、对外：脱敏案例库 / 方法论 / IP 素材

> 只有用户明确要求"沉淀成对外素材"时才整理；默认不对外。

- **脱敏原则**：删去人名/公司/城市/金额等可识别信息，事件保留结构不保留细节。
- **案例卡**：事件背景 → 三层拆解 → 一句真话 → 纠正动作 → 结果，一段 200-300 字。
- **方法论**：把反复验证有效的拆解路径提炼成"套路"（如"被拒绝时的三层拆解"）。
- **模板**：察觉报告模板、周报模板可作免费内容。
- **IP 素材**：金句库（SKILL.md 末尾）+ 案例卡 + 方法论，供朋友圈/小红书/B站复用。
