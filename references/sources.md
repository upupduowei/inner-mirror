# 经典深度链接索引（sources.md）

本文件是三层拆解镜的**深度兜底入口**：`references/psych.md`、`social.md`、`history.md` 只放操作框架，模型自带知识底座。当用户问"这背后的理论/经典研究是什么"、或当前框架不够用需要更系统的参照时，从这里取链接精读。

## 使用规则

1. 只在对话中需要更深依据时使用；日常察觉不需要打开。
2. 引用时给出**具体篇目/章节/观点**，不堆链接列表。
3. 经典书籍优先给"可检索的章节主题"，便于快速定位。

## 心理层（认知偏差 / 情绪回路）

- **《思考，快与慢》**（卡尼曼）：系统 1/系统 2、锚定、可得性、损失厌恶——偏差清单的源头。
- **《认知觉醒》**（周岭）：情绪脑/理智脑、元认知——"看见回路"的可操作版本。
- **《也许你该找个人聊聊》**（戈特利布）：心理治疗视角下的自我叙事，适合"自我故事"察觉。
- **认知行为疗法（CBT）基础**：认知三角（想法-情绪-行为）——情绪回路识别的临床来源。
- 搜索建议：`认知偏差列表 决策科学`、`CBT 认知三角 自动思维`、`情绪粒度 情绪命名`

## 社经层（结构归因 / 系统位置）

- **《置身事内》**（兰小欢）：中国政府与经济发展的结构逻辑——理解"系统位置"。
- **《贫穷的本质》**（班纳吉/迪弗洛）：结构约束如何塑造个体决策——"同一规则不同起点"。
- **《纳瓦尔宝典》**：杠杆（劳动力/资本/代码/媒体）、特定知识——个体在系统里加杠杆。
- **《影响力》**（西奥迪尼）：互惠/承诺/权威等机制——理解交易与说服结构。
- 搜索建议：`委托-代理问题 激励扭曲`、`信息不对称 商业谈判`、`平台经济 个体劳动者 处境`

## 历史社科层（长周期参照）

- **《人类简史》**（赫拉利）：大尺度视角——把个人处境放到文明尺度看。
- **《金钱心理学》**（豪塞尔）：复利、尾部事件、长期主义——"越早越好"的实证叙事。
- **《置身事内》** 兼作产业周期参照；**《浪潮之巅》**（吴军）：技术与产业周期中的个体与公司。
- **《被讨厌的勇气》**（岸见一郎/古贺史健）：课题分离——"冲突与边界"的哲学底子。
- 搜索建议：`产业生命周期 采用曲线`、`复利思维 长期主义 案例`、`人生阶段 发展心理学 课题`

## 画像机制参照（察觉复利闭环）

- **习惯回路**（《习惯的力量》，查尔斯·都希格）：提示-惯常行为-奖赏——"能量泄漏点"的模型来源。
- **元认知训练**：对思维过程的观察与调节——"察觉是有复利的"的认知科学依据。
- **成长型思维**（德韦克）：把失败当反馈——"归因校准"的教育心理学来源。
- 搜索建议：`元认知 自我监控 训练`、`习惯回路 提示 奖赏`、`成长型思维 归因方式`
