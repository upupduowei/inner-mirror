# 心理层拆解框架

心理层回答的问题：**这件事里，有多少是我的认知偏差和情绪回路造成的？**

## 使用规则

1. 先用用户原话里的行为/感受定位，不贴标签、不说教。
2. 每给一个偏差判断，必须配一句"你在原文里的证据"。
3. 只点最相关 1-2 个偏差，不要一次堆十个。

## 高频认知偏差（按场景查）

| 场景信号 | 常见偏差 |
|---|---|
| 反复担心最坏结果 | 灾难化（catastrophizing） |
| 把一次失败当永久定性 | 过度概括（overgeneralization） |
| 只看见负面证据 | 选择性注意（confirmation bias） |
| 因为一个缺点否定全部 | 光环/恶魔效应（halo/horn effect） |
| "应该""必须"式自我要求 | 应该思维（should statements） |
| 把情绪当事实 | 情绪化推理（emotional reasoning） |
| 归因到自己或他人单一原因 | 归因偏差（fundamental attribution error） |
| 想象被评价/被拒绝 | 读心术（mind-reading） |

## 情绪回路识别法

1. **触发**：什么具体事件/语言触发了情绪？（找客观事实，不是主观想象）
2. **解释**：我给自己讲了个什么故事？（通常是一句带评判的内心独白）
3. **感受**：身体的反应是什么？（胸口紧、胃部不适、想逃、想辩解）
4. **行为**：我做了什么？（回避/攻击/自我怀疑/过度补偿）

四步连起来就是一条"回路"。察觉的目标是**让回路被看见**——看见即打断。

## 输出句式

- 心理层结论：**"这件事里，你的『XX偏差』起作用了——证据是你说的『……』。"**
- 情绪回路总结：**"你的回路是：『XX触发 → 你把它解释成XX → 身体出现XX反应 → 你做了XX』。"**

## 注意

- 心理层认下"我的锅"，但不替用户认"不是他的锅"的锅——那是社经层的活。
- 用户明显有长期/严重心理困扰时，如实建议寻求专业帮助，不做诊断。
