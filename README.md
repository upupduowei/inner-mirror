# Inner Mirror · 内心之镜

> 遇事向 AI 提问，让 AI 帮你用上帝视角看清自己。

**Inner Mirror** 是一个 AI 自我察觉技能（Skill）：当你遇到问题、陷入情绪或纠结时，向 AI 倾诉，AI 会作为一面"不做保姆的镜子"，用**三层拆解镜**帮你拆开归因、校准认知，给你**一句不舒适的真话**和一个**可执行的纠正动作**，并把每次察觉沉淀成你的**个人认知画像**。

这不是日记——你不需要定期记录。它是**按需的镜子**：有事就照，无事不扰。

---

## 为什么做这件事

AI 时代最该外包的不是思考，而是看见自己。

大多数人内耗的根源，是**归因错位**：把结构的锅算到自己头上，把阶段性的难受当成终身的失败，把一次被拒解读成"我不行"。Inner Mirror 用三个学科视角帮你把归因拆开：

| 层 | 拆什么 | 回答的问题 |
|---|---|---|
| 心理层 | 认知偏差、情绪回路 | 有多少是我的"锅"？ |
| 社经层 | 结构归因、系统位置 | 有多少是结构的"锅"？ |
| 历史社科层 | 长周期参照 | 这正常吗？我在什么阶段？ |

## 核心机制

- **三层拆解镜**：心理层认下"我的锅"，社经层还回"结构的锅"，历史层框出"阶段的锅"——归因从此校准。
- **反顺从设计**：每次必须给一句"你可能不想听，但……"的真话。镜子不做保姆。
- **一个动作**：每次只给一个可执行的纠正动作，不堆建议。
- **察觉复利闭环**：单次察觉 → 30 天模式库 → 个人认知画像（高频触发点 / 重复归因偏差 / 能量泄漏点）。
- **认知画像墙**：连续打卡、六维进度（模式识别 / 归因校准 / 情绪察觉 / 真话勇气 / 行动落地 / 能量管理）、察觉卡集、成就徽章——察觉是有复利的，画像就是你的复利账户。

## 快速开始

### 安装为 Skill

将本目录放到 Agent 的 `.user_skills/` 目录下（与你的其他自定义技能并列）：

```bash
# 示例（以常见环境为例，路径以你的实际 Agent 环境为准）
cp -r inner-mirror <你的skill根目录>/.user_skills/
```

### 使用

安装后，直接对 AI 说类似这样的话即可触发：

- "帮我察觉一下今天这件事"
- "拆解一下我为什么总是……"
- "分析我的情绪 / 纠结 / 内耗"
- "复盘一下我今天的反应"

AI 会按主流程执行：**倾听还原 → 三层拆解 → 一句真话 → 一个动作 → 更新画像 → 追问落地**。

```

│   ├── social.md               # 社经层拆解框架（结构归因、系统位置）

│   └── portrait.md             # 画像数据更新规则（六维加权、徽章、DATA 结构）

```

## 产出物

| 层 | 产出 |
|---|---|
| 单次 | 察觉报告（含一句真话）+ 动作卡 |
| 周期 | 察觉周报 / 月报（高频触发点、重复归因偏差、能量泄漏点） |
| 长期 | 认知画像（六维进度、年度对比） |
| 对外 | 脱敏案例库、方法论、模板、IP 素材 |

## 三硬规则

1. **反顺从**：每次必须给"一句不舒适的真话"。
2. **一个动作**：每次只给一个可执行动作。
3. **可积累可回看**：每次察觉必须沉淀成卡/画像，说完就散等于没察觉。
